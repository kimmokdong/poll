# 마음신호

모두가 동시에 비밀 선택하고, 서로 다른 정보를 합쳐 추리하고, 결과를 단계적으로 공개하는 교실용 실시간 투표 게임입니다.

## 실행

Node.js 20 이상이 설치된 교실 PC에서 아래 명령만 실행합니다.

```powershell
npm start
```

교사는 브라우저에서 `http://localhost:4173`을 열고, 학생은 실행 화면에 표시된 같은 와이파이용 주소로 접속합니다. 별도 회원가입이나 외부 데이터베이스는 필요하지 않습니다.

## 교실 TV 화면

- 교사 화면의 `📺 교실 TV 열기`를 누르면 읽기 전용 공개 화면이 새 창으로 열립니다.
- TV 화면에서 `전체화면 + 긴장감 BGM 시작`을 한 번 누르면 단계별 생성형 BGM과 결과 효과음이 시작됩니다.
- TV에는 방 코드·타이머·제출 인원·공개 단서·결과만 표시되며, 학생 이름·개별 선택·비밀 임무는 전송되지 않습니다.
- 교사가 다음 단계나 결과 공개를 누르면 TV도 실시간으로 자동 전환됩니다.

## 사용 설명 자료

- 게임 첫 화면의 `📘 사용설명서` 버튼 또는 `http://localhost:4173/manual/`에서 교사용·학생용·교실 TV용 실제 화면 안내를 볼 수 있습니다.
- 설명서 원본은 `manual/index.html`이며 실제 작동 화면 20장을 포함합니다.
- 게임 모드 설명용 발표 자료는 `260822_game_mode_guide/output/index.html`과 `260822_game_mode_guide/output/presentation.pptx`입니다.
- PPTX는 검증된 1280×720 슬라이드 이미지를 한 장씩 넣은 발표용 파일입니다. 내용 수정은 HTML과 `slide_plan.json`에서 하는 것이 가장 안전합니다.

## 포함된 모드

- 정식 투표
- 결과 쇼
- 표심전
- 표심 이동전
- 소수파 생존
- 정확히 N명
- 정보 연합전
- 비밀 목표전

실제 의사결정에는 정식 투표·결과 쇼·표심전·표심 이동전을, 표 자체가 전략 자원이 되는 나머지 모드는 순수 게임 활동에 사용하세요.

## 운영 원칙

- 학생의 개별 선택은 교사 화면에도 표시하지 않습니다.
- 개인 점수는 해당 학생 화면에만 표시합니다.
- 학급방·참가자·점수는 `data/rooms.json`에 저장되어 서버를 다시 켜도 유지됩니다.
- 브라우저에 입장 정보가 저장되므로 학생은 같은 기기에서 자동 재입장합니다.
