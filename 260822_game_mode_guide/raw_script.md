# 사용자 원문 보존

> 게임모드의 경우에는 설명 ppt가 필요할듯 슬라이드스킬써서 ppt도 만들어줘.
>
> 이 작업들을 병렬로 작업해서 빠르게 하길 바래.

## 확정된 제작 조건

- 용도: 교사가 게임 시작 직전 전자칠판으로 학생에게 설명
- 대상: 초등 고학년 학생
- 화면: 16:9 교실 프로젝터, 1280×720 기준
- 분량: 10분 이내, 14장
- 모드: 정식 투표, 결과 쇼, 표심전, 표심 이동전, 소수파 생존, 정확히 N명, 정보 연합전, 비밀 목표전
- 공통 설명 순서: 목표·선택 → 중간 정보·재선택 → 승리·점수·공정성 주의
- 교사의 세부 운영 팁은 화면이 아니라 `SPEAKER_NOTES`에 보존
- 규칙 출처: 현재 프로젝트의 `server.js`, `public/app.js`, `README.md`
- 시각 출처: 현재 프로젝트의 `public/assets/app-icon.png`, `hero-classroom.png`, `mode-atlas.png`, `skill-atlas.png`

## 핵심 원칙

실제 학급 의사결정에는 정식 투표·결과 쇼·표심전·표심 이동전을 사용한다. 표 자체가 전략 자원이 되는 소수파 생존·정확히 N명·정보 연합전·비밀 목표전은 순수 게임으로만 사용한다. 학생의 개별 선택은 교사 화면에도 표시하지 않는다.
