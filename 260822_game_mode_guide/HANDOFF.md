# 마음신호 게임모드 설명 덱 인수인계

## 핵심 결과물

- 발표·검토·수정 원본: `output/index.html`
- 구조화 원본: `slide_plan.json`
- 최종 배포본: `output/presentation.pptx`
- 슬라이드별 캡처: `output/captures/slide-001.png` ~ `slide-014.png`
- 전체 축소 검수판: `output/captures/contact-sheet.png`
- 4층 QA 보고서: `output/captures/qa-report.json`

## 구성

- 총 14장, 16:9, 1280×720
- 초등 고학년 학생 수업, 교실 프로젝터, strict 품질 계약
- 8개 모드 전체와 표심전 정보 아이템 포함
- 교사용 세부 규칙·예외·진행 팁은 각 장의 `SPEAKER_NOTES`에 보존

## 검수 결과

- 데이터 오류: 0
- 시각 오류: 0
- 의미 오류: 0
- 수업 오류: 0
- 경고: 1 (`lesson-flow-order`)

경고 1건은 이 덱이 하나의 개념을 직선 순서로 가르치는 수업이 아니라, 모드별 성격에 따라 로드맵·타임라인·비교·O/X·도식 화면을 교차하는 게임 시작 전 참고 덱이기 때문에 발생한 의도적 흐름 알림이다. 글자 하한, 6줄 예산, 에셋, 잘림, 겹침 검사는 모두 통과했다.

## 독립 QA 규칙 교정

- 표심 이동전: `1차 비밀투표 → 혼잡도 공개와 이동 예측 → 최종 선택` 순서로 화면과 노트를 일치시켰다.
- 시작 최소 인원: 표심 이동전·소수파 생존·정확히 N명·정보 연합전은 2명, 비밀 목표전은 3명으로 노트에 명시했다.
- 소수파 생존의 기본값 3은 시작 인원이 아니라 승리 자격 최소 유효표이며, 교사가 1~20으로 설정한다.
- 소수파 생존·정확히 N명·비밀 목표전은 중간 신호 뒤 최종 선택 단계에서 변경할 수 있고, 교사가 다음 단계로 넘기기 전까지 다시 제출할 수 있다고 명시했다.
- 정식 투표·결과 쇼·표심전은 실제 표가 고정되고, 표심 이동전은 토론 뒤에도 1인 1표를 유지하며 최종 선택을 변경할 수 있다고 구분했다.

## PPTX 형식 주의

`presentation.pptx`는 검증된 PNG 14장을 각 슬라이드에 꽉 채운 **이미지형 PPTX**다. PowerPoint에서 바로 재생할 수 있지만 텍스트·도형을 네이티브 개체로 편집하는 파일은 아니다. 내용 수정은 `slide_plan.json` 또는 로컬 리뷰 모드의 HTML에서 완료한 뒤 다시 빌드·캡처·내보내기한다.
