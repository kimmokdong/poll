# 마음신호 사용설명서 워크플로 인벤토리

## 독자와 목표

- 교사: 처음 학급방을 만들고 학생을 입장시킨 뒤 첫 라운드를 안전하게 끝낸다.
- 학생: 교사가 보낸 참여 링크를 열거나 메인 화면에서 5자리 학급 코드와 이름을 입력한 뒤, 자신의 화면에서 제출하고 결과와 개인 점수를 확인한다.
- 교실 TV: 읽기 전용 공개 화면을 열고 사운드를 시작한 뒤 참여 현황과 결과 쇼를 교실 전체에 보여준다.
- 전달 형식: `/manual/`과 `file://`에서 모두 열리는 단일 `index.html`.

## 확인된 실제 흐름

| 역할 | 실제 흐름 | 증거 | 상태 |
|---|---|---|---|
| 교사 | 첫 화면 → 새 학급방 → 대시보드 → 표심전 설정 → 진행 화면 → 결과 공개 | `01`, `02`, `03`, `06`, `07`, `09`, `12` PNG | 확인됨 |
| 학생 | 참여 링크 또는 5자리 코드 입장 → 대기실 → 비밀투표 → 예측 → 정보 상점 → 결과 | `01`, `04`, `05`, `08`, `10`, `11`, `13` PNG, 브라우저 실검 | 확인됨 |
| 교실 TV | 교사 화면에서 TV 열기 → BGM 시작 → 참여 링크 안내 → 제출 현황 → 결과 봉인 → 단계 공개 → 최종 승리 | `14`~`20` PNG | 확인됨 |
| 동기화 | 학생 제출 뒤 교사 ‘현재 제출’이 `0/1`에서 `1/1`로 변경 | `07`, `09` PNG | 확인됨 |
| 비밀성 | TV 공개 상태에는 학생 이름·개별 선택·비밀 토큰이 없고 집계 수만 표시됨 | `17` PNG, 공개 API, 자동 테스트 | 확인됨 |

## 화면·설정 인벤토리

- 첫 화면: 새 학급방 만들기, 기존 방 관리, 사용설명서, 학급 코드로 들어가기. 학생은 참여 링크 또는 교사 화면의 5자리 코드로 입장.
- 새 방: 반 이름, 교사 이름, 숫자 4자리 PIN.
- 교사 대시보드: 교사용 5자리 코드, 학생 참여 링크 복사, 교실 TV 열기, 압축형 8개 모드 선택기, 참여 명단, 팀 점수.
- 공통 라운드 설정: 제목, 선택지 2~6개, 시간, 공개 방식, 학생 결과 범위, 자동 진행.
- 모드별 추가 설정: 정확히 N명 정원, 소수파 최소 인원, 소수파·비밀목표 역할 카드, 정보연합 거짓 단서.
- 교사 진행: 현재 단계, 타이머, 참여 인원, 현재 제출, 다음 단계, 교실 TV 열기, 시간 설정, 라운드 종료.
- 학생 진행: 대기, 선택, 예측, 정보 아이템, 단서·팀 답안, 결과·개인 점수.
- 교실 TV 진행: 학생 참여 링크 안내·접속 수, 타이머, 제출 수, 공개 신호, 봉인 화면, 결과 막대, 모드별 승리 판정, BGM·전체화면·코드 숨김.

## 근거 경계

- 실제 캡처 20장은 공개 서비스의 임시 학급방, 학생 1명, 표심전 한 라운드로 생성했다.
- 교사·학생·교실 TV를 서로 다른 브라우저 세션으로 연결해 입장부터 결과 확정까지 같은 방 상태로 캡처했다.
- 모드별 최소 인원·단계·설정 차이는 `src/worker.js`와 `public/app.js`를 교차 확인했다.
- 8개 모드의 진행 단계·승리/점수·교사 주의사항은 `src/game.js`의 단계·채점 규칙과 `public/app.js`의 설정 UI를 교차 확인해 HTML 상세 안내에 반영했다.
- 게임 모드 PPTX는 교실 앞에서 설명하기 위한 발표 자료로 유지하며, HTML 설명서만 읽어도 운영할 수 있도록 같은 핵심 규칙을 제공한다.
- 초보자가 문장을 다시 해석하지 않도록 화면 설명은 행동을 먼저 쓰고, 확인 문구와 주의 문구를 분리했다. 게임 모드 설명 순서는 `이럴 때 써요 → 진행 순서 → 승리·점수 → 꼭 확인`으로 통일했다.
- 설치·공개 배포·학교 네트워크 방화벽 설정은 이 문서 범위가 아니다.
