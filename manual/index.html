마음신호는 교사가 방을 열고, 학생이 자기 기기에서 비밀 선택을 보내며, 교실 TV가 참여 현황과 결과를 모두의 무대로 보여주는 투표 게임입니다. 아래 실제 화면을 순서대로 따라가면 첫 라운드까지 약 3분이면 충분합니다.

System overview

먼저, 마음신호가 어떻게 움직이나요?

세 화면은 같은 학급방을 보지만 역할이 다릅니다. 교사는 조작하고, 학생은 비밀 선택하며, 교실 TV는 모두에게 공개해도 되는 정보만 보여줍니다.

한 줄 정신 모델

교사는 무대감독, 학생 기기는 비밀 투표함, TV는 공동 무대

교사가 질문과 진행 단계를 열면 학생 화면과 TV가 동시에 바뀝니다. TV에는 몇 명이 제출했는지만 나타나며, 학생 이름·개별 선택·비밀 임무는 전송되지 않습니다.

기억할 것: 학생에게는 교사 화면에서 복사한 참여 링크만 보내고, 교사 PIN은 관리 화면을 다시 여는 개인 열쇠이므로 공유하지 않습니다.

👩‍🏫 교사가 하는 일

학급방을 만들고, 모드·질문·시간·공개 범위를 정하고, 제출 인원을 보면서 다음 단계와 결과 공개를 진행합니다.

🧑‍🎓 학생이 하는 일

선생님에게 받은 참여 링크를 열고 이름만 입력한 뒤, 자신의 기기에서 선택·예측·팀 답안을 제출하고 비밀 단서를 확인합니다. 화면에서 제출 버튼이 활성화된 항목은 같은 단계 안에서 다시 내면 마지막 답이 저장됩니다. 최종 예측·정보 아이템·역할 제한은 화면 안내를 따르세요.

📺 교실 TV가 하는 일

현재 단계·타이머·제출 인원·공개 단서·결과 연출을 모두에게 보여줍니다. 이름과 개인 선택은 표시하지 않으며 조작도 할 수 없습니다.

⚠️ 자주 헷갈려요

교사 PIN을 학생에게 공유하거나, 실제 학급 의사결정에 완전 게임 모드를 사용하는 것.

✓ 이렇게 시작하세요

첫 사용은 자동 진행을 끄고 교실 TV를 먼저 연 뒤, 정식 투표나 결과 쇼로 한 라운드 연습하세요.

          Quick reference

          진행 전에 이것만 확인하세요

          처음에는 설정을 단순하게 잡는 것이 좋습니다. 익숙해진 뒤에 자동 진행과 게임 전용 규칙을 더하세요.

          교사 설정

          질문과 선택지

          선택지는 2~6개입니다. ‘정확히 N명’에서는 각 선택지의 정원도 함께 넣습니다.

          • 단계 시간: 없음·20초·30초·45초·1분·2분
          • 공개: 낮은 순위부터·드럼롤·한 번에
          • 학생 결과: 득표수·1위만·숨김
          첫 사용 권장

          자동 진행은 끄기

          자동 진행은 시간이 끝나면 미제출 학생이 있어도 다음 단계로 넘어갑니다. 첫 수업은 끄고 제출 수를 본 뒤 직접 진행하세요.

          • ‘라운드 종료’는 현재 제출로 즉시 끝냅니다.
          • 다음 단계 전 제출 수를 확인하세요.
          학생 제출

          활성화된 제출은 마지막 답이 저장돼요

          화면에서 제출 버튼이 활성화된 항목은 같은 단계 안에서 다시 내면 마지막 답이 저장됩니다. 최종 예측·정보 아이템·역할 제한은 화면 안내를 따르세요.

          • ‘선택 완료’ 또는 저장 완료 문구를 확인하세요.
          • 정보 연합전의 팀 답안은 마지막 제출이 팀 전체 답을 덮어씁니다.
          교실 TV

          소리는 한 번 눌러 시작

          브라우저 정책상 ‘전체화면 + 긴장감 BGM 시작’을 눌러야 음악과 효과음이 시작됩니다.

          • M: BGM 켜기·끄기
          • F: 전체화면
          • C: 방 코드 숨기기·보이기
          모드권장 쓰임필요 인원진행에서 달라지는 점
          정식 투표 · 결과 쇼실제 학급 결정제한 없음투표 → 공개 → 완료. 결과 쇼는 공개 방식을 골라야 연출이 살아납니다.
          표심전공정한 결과 예측제한 없음투표 → 1차 예측 → 정보 상점 → 최종 예측 → 공개.
          표심 이동전토론 전후 변화2명 이상투표 → 중간 신호·협상 → 최종 선택 → 공개.
          소수파 생존 · 정확히 N명순수 게임2명 이상중간 신호 뒤 다시 선택합니다. 실제 의사결정에는 사용하지 않습니다.
          정보 연합전팀 논리 추리2명 이상비밀 단서 확인 → 팀 추리 답안. ‘거짓 단서 1개’ 설정은 이 모드에만 있습니다.
          비밀 목표전심리전3명 이상개인 임무 확인 뒤 투표합니다. 실제 의견 조사에는 사용하지 않습니다.
          Common checks

          화면이 뜻대로 움직이지 않을 때

          대부분은 참여 링크·브라우저·교사 설정을 확인하면 해결됩니다.

          학생이 참여 화면을 열 수 없어요.

          학생이 마음신호 메인 주소를 직접 연 것은 아닌지 확인하세요. 교사 화면에서 ‘학생 참여 링크 복사’를 다시 누른 뒤 그 링크를 보내야 합니다. 방이 24시간 넘게 사용되지 않았다면 새 학급방을 만들어 새 링크를 보내세요.

          학생은 들어왔는데 새 투표 화면이 안 보여요.

          교사 화면 오른쪽의 ‘참여 학생’에서 이름과 접속 표시를 먼저 확인하세요. 학생은 페이지를 새로 고쳐도 같은 브라우저라면 저장된 입장 정보로 돌아옵니다. 그래도 안 되면 교사가 보내 준 현재 접속 주소로 다시 여세요.

          결과가 학생 화면에 안 보여요.

          오류가 아닐 수 있습니다. 교사가 결과 표시를 ‘학생 화면 숨김’으로 정하면 끝까지 결과가 비어 있고, ‘1위만’이면 공개가 끝난 뒤 승자만 보입니다. 교사 화면에는 집계가 계속 표시됩니다.

          교실 TV에서 소리가 나지 않아요.

          TV 화면을 처음 열면 가운데 ‘전체화면 + 긴장감 BGM 시작’을 한 번 눌러야 합니다. 이미 화면만 시작했다면 오른쪽 아래 ‘🔇 BGM 켜기’를 누르세요. TV 자체 음소거와 브라우저 탭 음소거도 함께 확인합니다.

          교실 TV에 학생 이름이나 중간 득표수가 안 보여요.

          정상입니다. TV는 학생 이름·개별 선택·비밀 단서를 받지 않으며, 투표 중에는 제출 인원만 보여줍니다. 공개 단계에서만 교사가 정한 범위에 따라 결과가 나타납니다.

          교사 관리 화면을 닫아 버렸어요.

          같은 기기·브라우저라면 게임 주소를 다시 열면 자동 복귀합니다. 다른 기기에서 열거나 ‘나가기’로 세션을 지웠다면 ‘기존 방 관리’에서 방 코드와 4자리 교사 PIN을 입력하세요. PIN과 저장 세션을 모두 잃으면 기존 방을 다시 관리할 수 없습니다.

          예전에 만든 방이 더 이상 열리지 않아요.

          방은 마지막 입장·투표·진행 조작 뒤 24시간 동안 안전하게 보관되고, 활동이 없으면 개인정보와 임시 점수를 남기지 않도록 자동 정리됩니다. 하루가 지난 활동은 새 방을 만든 뒤 새 학생 참여 링크를 보내 주세요.

          표심전 정보 아이템 ‘저울’이 이상해요.

          저울 창을 처음 열면 A와 B가 같은 선택지로 보일 수 있습니다. B를 반드시 다른 선택지로 바꾼 뒤 사용하세요. 정보 아이템은 표심전의 ‘정보 상점’에서만 사용합니다.

          타이머가 끝났는데 그대로예요.

          자동 진행이 꺼져 있으면 정상입니다. 교사가 제출 인원을 확인한 뒤 ‘다음 단계’를 누릅니다. 시간은 ‘시간 설정’에서 현재 단계만 다시 시작할 수도 있습니다.
