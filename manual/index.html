화면 연결 이해하기

세 화면은 어떻게 연결되나요?

교사 화면에서 단계를 넘기면 학생 화면과 TV도 함께 바뀝니다. 학생의 이름·선택·비밀 정보는 TV에 나오지 않습니다.

가장 쉽게 기억하는 법

교사는 진행, 학생은 비밀 제출, TV는 함께 보는 화면

학생이 무엇을 골랐는지는 숨겨집니다. 교사와 TV에는 몇 명이 제출했는지만 보이고, 결과는 교사가 공개할 때 나타납니다.

👩‍🏫 교사 화면

방을 만들고 질문·모드·시간을 정합니다. 제출한 인원 수를 확인한 뒤 다음 단계와 결과 공개 버튼을 누릅니다.

🧑‍🎓 학생 화면

선생님이 보낸 링크를 열고 이름을 입력합니다. 선택·예측·팀 답안은 자기 기기에서 제출합니다. 수정할 수 있는 단계라면 다시 눌렀을 때 마지막 답이 저장됩니다.

📺 교실 TV 화면

질문·타이머·제출 인원·결과를 반 전체에 보여줍니다. 학생 이름과 개인 선택은 보여주지 않으며, TV에서는 게임을 조작할 수 없습니다.

⚠️ 이것은 하지 마세요

교사 PIN을 학생에게 보내지 마세요. 실제 학급 결정을 할 때는 소수파 생존·비밀 목표전 같은 완전 게임을 쓰지 마세요.

✓ 첫 투표는 이렇게 하세요

자동 진행을 끕니다. 교실 TV를 먼저 엽니다. 정식 투표 또는 결과 쇼로 짧게 연습합니다.

          첫 투표는 이렇게 설정하세요

          처음에는 정식 투표 또는 결과 쇼를 고르고 자동 진행을 끄세요. 익숙해진 뒤 다른 모드를 사용하면 됩니다.

          교사 설정

          질문과 선택지는 짧게

          선택지는 2~6개입니다. 학생이 한 번 읽고 바로 고를 수 있게 짧게 쓰세요.

          • 단계 시간: 처음에는 45초 권장
          • 결과 공개: 낮은 순위부터 권장
          • 학생 결과: 처음에는 득표수까지 권장
          첫 사용 권장

          자동 진행은 꺼 두세요

          자동 진행을 켜면 시간이 끝나는 즉시 다음 단계로 넘어갑니다. 첫 수업은 제출 인원을 보고 선생님이 직접 넘기세요.

          • 다음 단계 전: 제출 수 확인
          • ‘라운드 종료’: 현재 답으로 즉시 끝남
          학생 제출

          ‘선택 완료’를 확인하세요

          ‘선택 완료’ 또는 ‘저장 완료’가 보이면 제출된 것입니다. 수정할 수 있는 단계에서는 다시 제출한 마지막 답이 저장됩니다.

          • 최종 예측·아이템은 화면 안내 확인
          • 팀 답안은 마지막 제출이 팀 전체 답
          교실 TV

          소리는 첫 화면에서 시작해요

          TV를 연 뒤 ‘전체화면 + 긴장감 BGM 시작’을 한 번 눌러야 음악과 효과음이 나옵니다.

          • M: BGM 켜기·끄기
          • F: 전체화면
          • C: 방 코드 숨기기·보이기
          모드권장 쓰임필요 인원진행에서 달라지는 점
          정식 투표 · 결과 쇼실제 학급 결정제한 없음투표 → 공개 → 완료. 결과 쇼는 공개 방식을 골라야 연출이 살아납니다.
          표심전공정한 결과 예측제한 없음투표 → 1차 예측 → 정보 상점 → 최종 예측 → 공개.
          표심 이동전토론 전후 변화2명 이상투표 → 중간 신호·협상 → 최종 선택 → 공개.
          소수파 생존 · 정확히 N명순수 게임2명 이상중간 신호 뒤 다시 선택합니다. 실제 의사결정에는 사용하지 않습니다.
          정보 연합전팀 논리 추리2명 이상비밀 단서 확인 → 팀 추리 답안. ‘거짓 단서 1개’ 설정은 이 모드에만 있습니다.
          비밀 목표전심리전3명 이상개인 임무 확인 뒤 투표합니다. 실제 의견 조사에는 사용하지 않습니다.
          게임 모드 자세히 보기

          먼저 ‘실제 투표’인지 ‘게임’인지 정하세요

          모드 이름을 누르면 언제 쓰는지, 어떤 순서로 하는지, 누가 점수를 받는지가 열립니다.

          실제 의견을 묻나요? → Lv.0~3정식 투표, 결과 쇼, 표심전을 고르세요. 모든 학생의 표는 똑같이 1표입니다. 표심 이동전은 토론 전후 변화를 볼 때만 사용하세요.
          놀이가 목적이죠? → Lv.4소수파, 정원, 단서, 비밀 임무가 승패를 만듭니다. 시작 전에 “지금부터 게임 투표입니다”라고 알려 주세요.
          Lv.0 · 공정 투표✓ 정식 투표가장 단순하고 조용한 비밀 투표

          이럴 때 써요: 학급 행사, 역할 선정, 실제 의견 조사처럼 결과가 중요한 투표.

          진행 순서: 학생이 비밀 투표 → 교사가 결과 공개 → 결과 확정.

          결과: 모두 똑같이 1표입니다. 가장 많이 받은 선택지가 1위가 됩니다. 게임 점수는 없습니다.

          꼭 확인: 민감한 질문이라면 학생 결과를 ‘1위만’ 또는 ‘학생 화면 숨김’으로 정하세요.

          Lv.1 · 공정 투표🎬 결과 쇼표는 그대로 두고 공개 순간만 극적으로

          이럴 때 써요: 실제 투표는 공정하게 하고, 발표 순간만 재미있게 만들고 싶을 때.

          진행 순서: 비밀 투표 → 낮은 순위부터·드럼롤·한 번에 중 하나로 공개 → 결과 확정.

          결과: 정식 투표와 같은 1인 1표입니다. 점수는 없고 공개 연출만 달라집니다.

          꼭 확인: TV에서 BGM을 먼저 켜세요. 처음에는 ‘낮은 순위부터’를 권장합니다.

          Lv.2 · 공정 투표🔮 표심전반 전체의 1·2위와 표 차이를 읽는 예측전

          이럴 때 써요: 실제 선택은 그대로 두고, ‘우리 반의 마음’을 누가 잘 읽는지 겨룰 때.

          진행 순서: 비밀 투표 → 1차 예측 → 정보 토큰 사용 → 최종 예측 → 결과 공개.

          점수: 1위 3점 + 2위 2점 + 표 차이 2점. 세 가지를 모두 맞히면 2점 추가, 남은 토큰은 개당 1점입니다.

          꼭 확인: 예측과 정보 아이템은 실제 표를 바꾸지 않습니다. 세컨드 찬스가 있어야 최종 예측을 한 번 고칠 수 있습니다.

          Lv.3 · 전략 투표↝ 표심 이동전토론 전후에 몇 표가 움직일지 예측

          이럴 때 써요: 토론 전과 후에 반의 생각이 얼마나 달라졌는지 볼 때. 학생 2명 이상이 필요합니다.

          진행 순서: 1차 투표 → 혼잡도 공개·토론 → 변화 예측 → 최종 투표 → 결과 공개.

          점수: 바꾼 학생 수, 1위 변경, 표 차이 변화. 하나를 맞힐 때마다 2점, 최대 6점입니다.

          꼭 확인: 중간에는 정확한 표 수가 아닌 혼잡도만 보입니다. 누가 표를 바꿨는지는 공개하지 마세요.

          Lv.4 · 완전 게임🚪 소수파 생존최소 인원을 넘긴 선택지 중 가장 적은 쪽이 승리

          이럴 때 써요: 너무 적지도, 너무 많지도 않은 팀을 만드는 심리전. 학생 2명 이상이 필요합니다.

          진행 순서: 1차 선택 → 혼잡도 공개·협상 → 최종 선택 → 결과 공개.

          승리: 최소 인원을 채운 곳 중 사람이 가장 적은 선택지가 승리합니다. 그곳 학생은 3점입니다.

          꼭 확인: 기본 최소 인원은 3명입니다. 아무 곳도 최소 인원을 못 채우면 승자가 없습니다. 실제 의견 조사에는 쓰지 마세요.

          Lv.4 · 완전 게임🚀 정확히 N명선택지마다 정원을 정확하게 맞추는 협력과 배신

          이럴 때 써요: “빨간 대피소 4명”처럼 정원을 정확히 맞추는 협력 게임. 학생 2명 이상이 필요합니다.

          진행 순서: 선택지별 정원 입력 → 1차 선택 → 혼잡도 공개·협상 → 최종 선택 → 결과 공개.

          승리: 정원을 정확히 채운 선택지는 모두 성공합니다. 성공한 곳의 학생은 3점입니다.

          꼭 확인: 정원보다 한 명 많거나 한 명 적어도 실패합니다. 학생 수에 맞는 정원을 입력하세요.

          Lv.4 · 완전 게임🧩 정보 연합전팀원이 받은 다른 단서를 합쳐 전체 결과 추리

          이럴 때 써요: 팀원끼리 다른 단서를 모아 전체 결과를 추리할 때. 학생 2명 이상이 필요합니다.

          진행 순서: 비밀 투표 → 각자 단서 확인 → 팀끼리 공유 → 순위·득표수 제출 → 결과 공개.

          팀 점수: 순위 위치 하나당 1점, 정확한 득표수 하나당 1점. 전체 순위를 모두 맞히면 3점이 추가됩니다.

          꼭 확인: 같은 팀은 같은 점수를 받습니다. 팀 답안은 마지막에 제출한 내용으로 바뀝니다.

          Lv.4 · 완전 게임🎭 비밀 목표전서로 다른 개인 승리 조건을 숨기고 설득

          이럴 때 써요: 학생마다 다른 비밀 임무를 받고 설득하는 강한 심리전. 학생 3명 이상이 필요합니다.

          진행 순서: 개인 임무 확인 → 1차 선택 → 혼잡도 공개·협상 → 최종 선택 → 결과 공개.

          승리: 자기 임무를 달성한 학생은 4점입니다. 임무는 1위 만들기, 2위 만들기, 박빙 만들기 등으로 서로 다릅니다.

          꼭 확인: 학생은 자기 의견보다 임무를 위해 표를 냅니다. 실제 학급 결정에는 절대 사용하지 마세요.

          문제 해결

          화면이 움직이지 않으면 이렇게 하세요

          아래에서 지금 보이는 문제를 누르세요. 가장 먼저 확인할 것부터 순서대로 안내합니다.

          학생이 참여 화면을 열 수 없어요.

          학생에게 메인 주소가 아니라 ‘학생 참여 링크’를 보냈는지 확인하세요. 교사 화면에서 ‘학생 참여 링크 복사’를 다시 눌러 보내면 됩니다. 방을 하루 넘게 사용하지 않았다면 새 방과 새 링크를 만드세요.

          학생은 들어왔는데 투표 화면이 안 보여요.

          교사 화면의 ‘참여 학생’에서 이름과 초록색 접속 표시를 확인하세요. 아직 게임을 시작하지 않았다면 학생에게는 대기 화면이 보이는 것이 정상입니다. 그래도 안 되면 현재 참여 링크를 다시 여세요.

          결과가 학생 화면에 안 보여요.

          오류가 아닐 수 있습니다. 교사가 결과 표시를 ‘학생 화면 숨김’으로 정하면 끝까지 결과가 비어 있고, ‘1위만’이면 공개가 끝난 뒤 승자만 보입니다. 교사 화면에는 집계가 계속 표시됩니다.

          교실 TV에서 소리가 나지 않아요.

          TV 화면을 처음 열면 가운데 ‘전체화면 + 긴장감 BGM 시작’을 한 번 눌러야 합니다. 이미 화면만 시작했다면 오른쪽 아래 ‘🔇 BGM 켜기’를 누르세요. TV 자체 음소거와 브라우저 탭 음소거도 함께 확인합니다.

          교실 TV에 학생 이름이나 중간 득표수가 안 보여요.

          정상입니다. TV는 학생 이름·개별 선택·비밀 단서를 받지 않으며, 투표 중에는 제출 인원만 보여줍니다. 공개 단계에서만 교사가 정한 범위에 따라 결과가 나타납니다.

          교사 관리 화면을 닫아 버렸어요.

          같은 기기·브라우저라면 게임 주소를 다시 열면 자동 복귀합니다. 다른 기기에서 열거나 ‘나가기’로 세션을 지웠다면 ‘기존 방 관리’에서 방 코드와 4자리 교사 PIN을 입력하세요. PIN과 저장 세션을 모두 잃으면 기존 방을 다시 관리할 수 없습니다.

          예전에 만든 방이 더 이상 열리지 않아요.

          방은 마지막 입장·투표·진행 조작 뒤 24시간 동안 안전하게 보관되고, 활동이 없으면 개인정보와 임시 점수를 남기지 않도록 자동 정리됩니다. 하루가 지난 활동은 새 방을 만든 뒤 새 학생 참여 링크를 보내 주세요.
