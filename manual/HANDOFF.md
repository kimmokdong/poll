# HANDOFF

## 완료한 것

- 교사·학생·교실 TV가 한 페이지에서 역할을 전환하는 사용설명서 제작.
- 세 역할의 6단계 전체 경로를 Workflow Map 내부와 상세 패널, 실제 화면 캐러셀에 동일 번호로 연결.
- 실제 앱에서 교사·학생 표심전 한 라운드를 끝까지 실행하고 캡처 13장 저장.
- 모든 캡처 카드에 성공 확인, 초보 실수, 콜아웃, 클릭 확대를 추가.
- `/manual/` HTTP, 1280px, 390px 모바일, 역할 전환, 캐러셀, 확대창, 콘솔을 검수.
- `file://`는 CLI의 프로토콜 차단 때문에 번들 Chromium 직접 실행으로 검수.
- 최종 독립 QA에서 공통 재제출 안내를 활성화된 제출 버튼으로 한정하고, 최종 예측·아이템·역할 제한과 교사 저장 세션 자동 복귀 조건을 교정했다.
- 교정 뒤 HTTP `/manual/`과 `file://`를 다시 열어 세 문구, 학생용 6단계 경로, 실제 이미지, 콘솔 오류 0을 확인했다. 증거 이미지는 `qa/http-copy-fix-1280.png`, `qa/file-copy-fix-1280.png`에 남겼다.
- 교실 TV 전용 흐름을 실제 격리 학급방에서 교사·학생 화면과 함께 실행하고, TV 열기·사운드 시작·대기·투표·봉인·공개·최종 승리 화면 7장을 추가했다.
- TV 공개 상태에는 학생 이름·개별 선택·비밀 토큰이 포함되지 않음을 API와 브라우저에서 확인했다. BGM 켜짐, 1600×900 무스크롤, 전체 단계 자동 동기화, 콘솔 오류 0도 검증했다.

## 캡처와 데이터 경계

- 최종 캡처에는 임시 방 코드와 예시 이름만 포함한다.
- 프로젝트 원본 `data/rooms.json`은 수정하지 않았다. 교실 TV 캡처는 시스템 임시 디렉터리의 격리 복사본에서만 방을 만들었다.
- 임시 복사본은 검증 뒤 제거했다. `/manual/` 정적 경로에는 앱 복제본이나 테스트 방 데이터가 남지 않는다.
